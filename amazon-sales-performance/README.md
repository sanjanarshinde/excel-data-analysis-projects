# Amazon Sales Analysis – Excel Project

## Project Overview

This project analyzes Amazon sales data using Microsoft Excel to understand sales performance, customer orders, product performance, categories, payment methods, sellers, locations, and returns.

The project covers the complete data analysis process from data cleaning and preparation to analysis, visualization, and dashboard creation.

## Objective

The main objectives of this project are to:

- Analyze overall sales performance
- Identify top-performing products and categories
- Analyze sales by year and month
- Understand order and quantity trends
- Analyze customer and location-wise sales
- Analyze payment methods
- Analyze seller performance
- Analyze returns and order status
- Build an interactive Excel dashboard

## Dataset

The dataset contains Amazon sales transaction-level data with fields such as:
